Rule reference

Operators: and or not < <= > >= == != + - * /. Functions: abs min max crossed_above(a,b) crossed_below(a,b). Strike: ATM, ATM+2, ATM-1 (strike steps) or a number.

Syntax example (not a recommendation)

entry: crossed_above(ema_9, ema_21) and hv_20 < 0.18
exit:  crossed_below(ema_9, ema_21)

Deploy to paper trading

Runs your strategy forward on new daily bars with virtual money. Deployments update automatically and on demand. Live broker execution is not enabled in this version.

Python SDK (self-hosted operators)

from engine.strategy_base import Strategy, Leg, RiskLimits

class MyStrategy(Strategy):
    name = 'My strategy'
    indicators = ['rsi_14', 'sma_50']      # computed for you, no look-ahead
    models = ['trend_5d']                  # your trained model -> ctx.value('model_trend_5d')
    risk = RiskLimits(stop_loss_pct=40, max_hold_bars=10)

    def on_bar(self, ctx):
        if ctx.position is None and ctx.value('model_trend_5d', 0) > 0.6:
            ctx.open([Leg('BUY', 'CE', 'ATM', lots=1, expiry_days=14)])
        elif ctx.position and ctx.value('rsi_14', 50) > 70:
            ctx.close('my exit')

Drop the file in plugins/ and restart. Plugins run with server privileges, so only the operator installs them.

Before you start

  • This platform is a software tool. It does not give investment advice, research, recommendations or buy/sell signals.
  • You write your strategies and choose and train your models. All trading decisions are yours.
  • Backtests use modelled option prices and are approximations. Past or simulated performance does not guarantee future results.
  • F&O trading carries a high risk of loss. SEBI studies show most individual F&O traders lose money.
  • This version supports paper trading only. Any future live execution would go through your SEBI-registered broker under its algo-trading rules.
